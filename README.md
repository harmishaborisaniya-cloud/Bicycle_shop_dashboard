# Bicycle_shop_dashboard (Interactive Dashboard Creation using MS Excel)
I developed a comprehensive project in Excel, creating multiple and tables and charts to analyze the data. This process involved several stages, including data preprocessing, data cleaning, and data visualization.

## Project Objective

To create an interactive sales and customer analysis dashboard to understand business performance, customer purchasing behavior, and product trends. This project helps identify important insights that can improve sales strategies and customer satisfaction.

## Bicycle Shop Dashboard Dataset (MS Excel)
<a href="https://github.com/harmishaborisaniya-cloud/Bicycle_shop_dashboard/blob/main/Bicycle%20Shop%20Dashboard.xlsx">Data_set</a>


* ## Questions (KPIs)

- Analyze Total Sales, Profit, Profit Percentage, and Units Sold.
- Compare monthly Sales and Profit trends.
- Identify the Top Selling Product.
- Analyze Sales generated by different customers.
- Compare Sales contribution by country.
- Analyze Units Sold split by product categories.
- Study Profit generated over different months.
- Compare Sales breakup by business segments.
- Create an interactive dashboard using slicers for Year and Month filtering.

## Process

* Collected and cleaned raw sales data in Excel.
* Checked for missing values, duplicate records, and formatting issues.
* Standardized data types and organized the dataset properly.
* Created pivot tables and pivot charts for analysis.
* Designed an interactive dashboard using slicers and filters.
* Added visualizations to make the dashboard user-friendly and dynamic.
